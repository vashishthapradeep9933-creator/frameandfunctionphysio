# Frame & Function Physiotherapy Clinic Website

Local workspace for **frameandfunctionphysio.com**.

## Project Structure
- `index.html` - Main landing page with full SEO, AEO, and Google Schema.
- `assets/` - CSS bundles, JS modules, icons, and client scripts.
- `images/` - Doctor photos and treatment media assets.
- `favicon.ico`, `favicon.svg` - Favicon files.
- `start_local_preview.bat` - Double-click to run and test locally on your browser.

## Deploy to Live:
Create a repository on your GitHub (`vashishthapradeep9933@gmail.com`) and connect it:
```bash
git remote add origin https://github.com/<YOUR_USERNAME>/frameandfunctionphysio.git
git branch -M main
git push -u origin main
```
